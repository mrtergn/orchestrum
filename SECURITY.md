# Security Policy

Orchestrum is a local-first system. We still take security issues seriously.

## Reporting a Vulnerability
If you discover a security issue:
1. Please do not open a public issue immediately.
2. Contact the maintainers with details and reproduction steps.

If a private channel is not available, open a GitHub issue and mark it as **security** with minimal details. We will follow up privately.

## Scope
Security concerns include:
- Remote code execution
- Path traversal
- Secrets leakage
- Unsafe sandbox escapes
- Arbitrary filesystem writes outside configured boundaries

## Supported Versions
Only the latest release is supported.
